## 3. 已知坑 (从其他 session 经验)

1. **Windows GBK console + `pa search --engine all`**: 会 `UnicodeEncodeError: 'gbk' codec can't encode character`。设 `PYTHONIOENCODING=utf-8` + `PYTHONUTF8=1` (持久化: `setx PYTHONIOENCODING utf-8`)
2. **git push 2nd attempt**: 第一次 push 可能直接通 (用 Windows Credential Manager),第二次会 "Connection reset"。retry 加 `-c http.proxy=http://127.0.0.1:10808`
3. **PubMed year filter**: 故意 trade-off,结果数可能 < limit (post-filter 跟 esearch 不一致)
4. **Pre-existing OpenAlex concept filter bug**: 返 0 结果,跟 v3.9.11.x 无关,别误归因
5. **force-push 后 tag SHA 全变**: 8 commits 全部新 SHA,git fetch 后 7 个新 commit "看起来像未推送" — 实际是 force-push 后的正常状态
